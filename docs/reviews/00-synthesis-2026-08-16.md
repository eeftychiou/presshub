## 3. Consolidated findings (deduplicated) — verified

### 🔴 High
1. **`run_review()` demotes published posts to `pending`** — `class-ajax-handlers.php:182-188`, no status guard. *Pre-existing bug.*
2. **Plugin header incomplete** (`presshub-ai-editor.php:1-7`) — missing `Requires at least`/`Requires PHP`/`Tested up to`/`License`/`Text Domain`/`Domain Path`; `v1.1` baked into Plugin Name. Blocks WP.org submission.
3. **No lifecycle hygiene** — no `register_deactivation_hook`, no `uninstall.php`; research crons + options survive uninstall.

### 🟡 Medium
4. **Missing `wp_unslash()` on 5 `$_POST` reads** (`class-ajax-handlers.php:102,103,164,200,214`) — apostrophes get backslash-corrupted in prompts/stored data.
5. **Preset-CRUD throttle dead by default / mis-bucketed** — reuses global AI limiter; effective limit ≠ documented 60/min.
6. **Per-provider "Test Connection" buttons inert** — `admin.js` doesn't send `provider`.
7. **`max_tokens` ignored for OpenAI and Gemini** — only Anthropic honors it.
8. **Research polling never terminates** (`sidebar.js`) — no attempt cap, no unmount cleanup; stuck `processing` posts poll forever.
9. **Orphaned uploads on rate-limit rejection** — files moved before limit check, cleanup after the die point.
10. **Two large inline `<script>` blocks** bypass `wp_enqueue_script` (admin submenu + author profile); duplicate `var presshubAI` risk; untranslatable strings.
11. **Admin submenu orphaned** under `options-general.php` with no parent menu.
12. **AJAX handlers re-implement Store semantics** (quota/collision logic in 3 handlers) — should be `Store::upsert/remove/copy_default_to_author`.
13. **Provider defaults duplicated** between `class-settings.php:67-86` and `class-api-client.php:30-51` — drift risk.
14. **API keys autoloaded on every request**; no UI path to revoke a key (empty/masked both map to existing).

### 🟢 Low / Nit (selected)
15. Upload type/size validation (whitelist + cap).
16. Research posts inserted `publish` then reverted by workflow guard — insert `pending` directly.
17. Gemini model path normalization (`models/models/…`).
18. Scorecard meta render guards (`is_array()`).
19. Stuck `processing` logs never cleaned; retention hardcoded (30d) despite docstring.
20. Imagen key in URL query → `x-goog-api-key` header.
21. Provider error messages echoed verbatim to clients.
22. i18n gaps (metabox, inline scripts, JS files).
23. `sanitize_gcloud_project_id` allows underscores; slug regex nit.
24. Rate limiter TOCTOU (non-atomic) — acceptable for cost control, document.
25. `current_user_can()` in cron/REST context (user 0) surprises CLI flows.

## 4. Proposed action plan (parent recommendation)

### Batch A — correctness & security quick wins (S effort, high value)
1. Fix High-1: status guard in `run_review()` (only transition non-`publish`).
2. Fix Medium-4: `wp_unslash()` on the 5 reads (+ extend harness to emulate slashing so it can't regress).
3. Fix Medium-7: `max_tokens` for OpenAI + `maxOutputTokens` for Gemini.
4. Fix Medium-6: send `provider` from `admin.js` test buttons.
5. Fix Medium-5: dedicated throttle enable flag on `Rate_Limiter` (constructor arg), align `record()`/`check()` args.
6. Fix Medium-8: cap sidebar polling (30 attempts), clear on unmount; include `processing` in stale-cleanup sweep.
7. Fix Medium-9: enforce rate limit before uploads (or `try/finally` cleanup).
8. Fix Low-16: insert research posts as `pending`.

### Batch B — plugin lifecycle & WP.org readiness (S/M)
9. Plugin header fields + remove version from Plugin Name.
10. `register_deactivation_hook` (clear both crons) + `uninstall.php` (options, user metas).
11. Move inline scripts into a proper enqueued asset with `wp_localize_script`; declare jQuery dep.
12. Options `autoload => false` for keys + explicit "Remove key" control.
13. Upload whitelist/size caps; Gemini `models/` normalization; scorecard render guards; retention option or docstring fix; Imagen `x-goog-api-key` header.

### Batch C — architecture refactors (M, follow-up)
14. `Store::upsert/remove/copy_default_to_author` — handlers shrink to auth+sanitize+delegate.
15. Single source of truth for provider defaults (one defaults class).
16. PHPUnit-lite runner (harness promotion) so CI stops hand-enumerating test files.
17. i18n sweep (`__()` everywhere + JS translations).
18. Document rate-limiter TOCTOU; revisit `current_user_can` in cron context.

**Recommendation:** ship Batch A next session (all TDD-able with existing harness), then B; C only if the plugin is heading to WP.org or v2.
